# Apple Customer Service RAG Chatbot

A documentation-only showcase of a group project completed for GE1362 GenAI. Course provider: Alibaba Cloud Academy.

**Portfolio:** https://github.com/harrelldg

## Project overview

The team prototyped an Apple customer-service assistant in Dify.ai using retrieval-augmented generation (RAG). The assistant answered product FAQs, compared devices, provided support guidance, and recommended products based on user needs.

## Approach

- Built and cleaned a knowledge base using Apple's public product and support information.
- Compared responses without RAG, with a small knowledge base, and with an expanded knowledge base.
- Tuned temperature, top-p, and output length for creative, balanced, precise, and concise response styles.
- Applied instruction design, few-shot prompting, variables, and safety testing.
